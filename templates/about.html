About This Archive

This is a read-only archive of the {{ config.site.short_name }} discussion forum, preserved as static HTML. The forum was active from {{ config.site.date_range }} and contains {{ stats.threads|commafy }} threads with {{ stats.posts|commafy }} posts from {{ stats.users|commafy }} members.

What's included

  • All public threads and posts
  • Forum structure and hierarchy
  • File attachments shared by community members
  • User-posted images (where originally hosted externally, links are preserved but images may no longer be available)

What's not included

  • Private messages
  • User profiles and personal data (email addresses, IP addresses, passwords)
  • User avatars and signatures
  • Post edit history
  • Content from banned/spam accounts

Finding content

  • Browse the forum index to explore by category
  • Search across all threads using Pagefind (runs entirely in your browser)
  • Statistics for an overview of forum activity over time

Privacy

This archive has been created with privacy in mind. Personal data has been minimised: email addresses, IP addresses, passwords, private messages, and date-of-birth fields have all been excluded. Usernames are retained as they were publicly visible during the forum's active life.

This archive is maintained under the GDPR Article 89 exemption for archiving in the public interest. If you would like your content removed, please contact us and we will process your request promptly.

Technical details

This archive was generated from a vBulletin 3.8 MySQL database using vbulletin-static-archive, an open-source static site generator built with Python, Jinja2, and a custom BBCode-to-HTML converter. Search is powered by Pagefind, which builds a static index and runs entirely client-side via WebAssembly — no server resources required.
